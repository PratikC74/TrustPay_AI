# TrustPay AI

AI-Powered Payment Risk & Decision Platform

## Features

- JWT authentication
- Admin role authorization
- Payment transaction management
- AI-based transaction risk assessment
- Low / Medium / High risk classification
- Approve / Review / Block decisions
- Payment execution
- Audit logging
- Transaction search and filters
- React dashboard
- PostgreSQL database
- Automated API tests

## Tech Stack

### Backend
- Python
- FastAPI
- SQLAlchemy
- PostgreSQL
- JWT
- OpenAI API with local risk fallback

### Frontend
- React
- Vite

### Database
- PostgreSQL
- Docker
